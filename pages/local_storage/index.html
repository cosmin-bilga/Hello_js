Le Local Storage

Le Local Storage est une fonctionnalité du navigateur qui permet de stocker des données sous forme de paires clé/valeur.

Contrairement aux cookies, les données stockées dans le Local Storage ne sont pas envoyées au serveur avec chaque requête HTTP, ce qui améliore les performances.

Le Local Storage est persistant, ce qui signifie que les données restent disponibles même après la fermeture du navigateur ou le redémarrage de l'ordinateur.

Le Local Storage est limité en taille (généralement autour de 5 Mo par domaine), mais il est suffisant pour stocker des données utilisateur, des préférences, ou des informations temporaires.

Le Local Storage est accessible via l'objet JavaScript localStorage, qui fournit des méthodes pour ajouter, récupérer, supprimer et gérer les données stockées.

Voici quelques méthodes courantes de l'objet localStorage :

  • setItem(clé, valeur) : Ajoute une paire clé/valeur au Local Storage.
  • getItem(clé) : Récupère la valeur associée à une clé spécifique.
  • removeItem(clé) : Supprime la paire clé/valeur associée à une clé spécifique.
  • clear() : Supprime toutes les paires clé/valeur du Local Storage.
  • key(index) : Récupère la clé à l'index spécifié.
  • length : Propriété qui retourne le nombre de paires clé/valeur stockées.

Exemple d'utilisation du Local Storage :

Ajouter une valeur :

localStorage.setItem('nom', 'Alice');

Récupérer une valeur :

const nom = localStorage.getItem('nom'); console.log(nom);

Supprimer une valeur

localStorage.removeItem('nom');

Vérifier si une clé existe

if (localStorage.getItem('nom')) { console.log('Nom trouvé'); } else { console.log('Nom non trouvé'); }

Vider le Local Storage
