Ajout/suppresion de classes css

Il est possible de modifier les classes CSS d'un élément HTML en utilisant les méthodes de l'interface classList et c'est tres pratique.

selectionner un élément HTML en utilisant des méthodes comme getElementById, querySelector, ou querySelectorAll.

puis, utilisez les méthodes de l'interface classList pour modifier les classes CSS de l'élément sélectionné.

Ajoutez une classe CSS à un élément en utilisant la méthode classList.add().

Retirez une classe CSS d'un élément en utilisant la méthode classList.remove().

Ou encore, vous pouvez ajouter une classe si elle n'existe pas et la retirer si elle existe en utilisant la méthode classList.toggle().
